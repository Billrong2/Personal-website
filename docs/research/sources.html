ASE 2026

CodeSteer

Post-Hoc Attention Steering of Large Language Models for Robust Code Understanding under Obfuscation

CodeSteer uses program-analysis relevance signals to steer model attention at inference time, improving reasoning about obfuscated code.

  • Backward slices guide output prediction.
  • Control-flow paths guide execution reasoning.
  • Attention is steered toward semantically relevant elements; this is training-free.
  • The paper includes a buffer-overflow detection case study.

演示边界：本地编写的教学示例；没有在浏览器运行论文模型，也不代表论文实验结果。

ISSTA 2026

AdaptAgent

AdaptAgent: A Multi-agent, Domain-Guided Reasoning Framework for Code Adaptation

Given a snippet, intent, target repository, and location, AdaptAgent coordinates specialized agents to produce an adapting patch.

  • Agents exchange typed artifacts.
  • Intent Summarizer extracts goals; Policy Agent derives rules from six adaptation categories.
  • Domain Planner orders the plan; Context Miner extracts sibling-method semantics.
  • Code Adapter produces a minimal unified diff; compiler-based Verifier supplies iterative feedback.

ICSE 2026

LλMDA

Large Language Model-Aided Partial Program Dependence Analysis

LλMDA fills missing context in partial code so conventional dependence analysis can work, then retains results relevant to the original snippet.

  • Two phases: Context Augmentation and Analysis.
  • Compiler feedback guides missing declarations, imports, and type information.
  • LLMs provide context rather than directly predicting dependence edges.
  • Traditional analysis runs on augmented code; extra-scope results are removed.
  • The paper implementation uses Joern with GPT-4o or Claude 3.5 Sonnet.

ISSTA 2026

Behavioral Alignment

On Behavioral Alignment of Model-Code and Human-Code Understandability via Behavioral Proxies

This work treats understandability as a relationship between code and its reader, and studies alignment between human judgments and model behavior.

  • P0 is a comprehension-question behavioral proxy.
  • P1–P3 use program-intent summaries and semantic self-consistency.
  • The study compares multiple LLMs with human-rated understandability across reader groups.
  • Alignment is strongest with professional developers; role prompts do not resolve weaker student-group alignment.

FSE 2025

PredEx

Blended Analysis for Predictive Execution

PredEx combines program analysis with model reasoning to predict Python execution traces.

  • Deterministic control-flow steps use program analysis.
  • Uncertain branch decisions use per-variable predictive backward slices.
  • Applications include code coverage and runtime-error prediction for complete or incomplete code.

ICSE 2025

SAFEMIN

Large Language Models for Safe Minimization

SAFEMIN pairs LLM proposals with SMT checking to reduce infeasible string-constraint systems while preserving unsatisfiability.

  • The retained subset must remain UNSAT.
  • The target is a minimal unsatisfiable subset (MUS).
  • A sample-and-enumerate strategy explores multiple MUSes.
  • The paper demonstrates infeasible-path detection.
