How the game works. Route two different signal stations into the mirror’s two sockets. Matching semantic labels light the mirror. The code verifier checks a separate condition: whether that shared meaning describes the displayed program. You can walk the courier with the keyboard or wire the city directly with touch or a pointer.
Authored teaching game. Signals, meanings, streets and verification fixtures are hand-written. No LLM, human ratings or paper measurements are loaded. This game illustrates semantic consistency versus correctness; it does not measure alignment with people.
